# Application de Gestion des Absences

Application web (PHP / MySQL) choisie comme fil rouge DevOps. Elle permet de gérer les absences des étudiants, la structure pédagogique (filières, modules, éléments, classes) et les demandes de justification.

## 1. Prérequis

Pour lancer ce projet sur votre machine, assurez-vous d'avoir installé :
- **Git**
- **Docker** et **Docker Compose**
